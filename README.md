# F# Exam Prep

A self-contained, fully local study application for an F# / functional-programming
university module: deep per-topic explanations, a searchable syntax reference,
auto-generated and auto-graded practice (including real F# code execution), a dedicated
structural-induction and lambda-calculus engine, timed/untimed exam simulation, progress
tracking, weakness detection, and a Code Lab with a step-by-step debugging tutor.

Everything runs on your own machine. There is no server, account, or subscription
involved beyond what's already on your computer.

## Is this safe to make public? Read this first

**No AI service is used anywhere in this application, and it is not connected to any
account.** Every explanation, question, and piece of feedback is generated by plain,
deterministic Python running on your own machine — template-based question generation,
a hand-written lambda-calculus interpreter, a structural-induction proof-checker, and
real F# code execution via the .NET SDK's `dotnet fsi`. There is no API key anywhere in
this codebase, no network calls to any AI provider, and nothing here can expose your
Claude/ChatGPT/etc. account or usage to anyone who gets a copy of this code. (You can
verify this yourself: there is no outbound network call in the entire `backend/` folder
except to `localhost`.)

**What this *can* expose, if you make the repository public, is the shape of your
course.** This app's curriculum content was written by analysing real course material
(lecture slides, past exam papers, homework, class tests) for a specific university
module, so that the practice questions and exam simulations actually match what's
examined. That means:

- The topic list, difficulty balance, and question *styles* closely mirror a real
  module's real past exam papers, even though no exam question is reproduced verbatim.
- Names of real people (lecturers, examiners) that appeared in the source material have
  been deliberately scrubbed from the code and content — but the module code itself is
  still present, and the resemblance to specific past exam questions (topics,
  structures, phrasing) is close by design.
- **The original source material is intentionally not part of this repository at
  all** — no lecture slides, no past exam papers, no textbook PDFs, no homework
  submissions. Only the generated study application (this code) is here.

Whether publishing study material this closely derived from real exam papers is fine
under your institution's academic integrity / plagiarism policy is a judgment call only
you can make with knowledge of that policy — this is not something I can certify as
safe. **If you're unsure, keep the repository private** (free on GitHub for personal
repos) rather than public. A private repo gets you version control and backup without
publishing anything to anyone.

Before pushing, it's worth doing a final check yourself:

```
grep -rniE "your real name|student number|lecturer name" backend/ frontend/
```

## Requirements

- Python 3.10+
- .NET SDK with `dotnet fsi` available — used to actually compile and run F# code for
  grading and the Code Lab. No internet connection is required once dependencies are
  installed; nothing here calls out to the internet at runtime.

## Running it

**Windows, no terminal:** double-click `Start F# Exam Prep.vbs` (or a desktop shortcut
to it) — it starts the server hidden in the background and opens your browser to it.
Double-click `Stop F# Exam Prep.vbs` to shut it down.

**Any platform, manual:**

```
cd backend
pip install -r requirements.txt   # first time only
python app.py
```

Then open **http://localhost:5000**. Closing the terminal (or Ctrl+C) stops the server.

Your progress, question history, and exam results are saved locally in
`backend/study.db` (SQLite, git-ignored) and persist between runs. Delete that file to
reset all progress.

## Architecture

```
backend/
  app.py               Flask API + routing
  curriculum.py         Topic content (7 explanation levels per topic)
  syntax_reference.py   Searchable syntax cheat-sheet entries
  questions.py           Parameterised question-bank templates (MCQ / trace / code-write)
  induction_proofs.py   Structural-induction proof library + fill-in-the-justification engine
  lambda_calc.py        A real lambda-calculus parser/evaluator (beta reduction, Church encodings)
  fsharp_runner.py      Sandboxed `dotnet fsi` execution + code-grading harness
  db.py                 SQLite persistence (progress, exposure tracking, exam history)
frontend/
  index.html, *.js, *.css   Plain HTML/CSS/JS single-page app, no build step, no framework
```

Question generation is stateless: each question's grading key travels with the question
object itself (round-tripped from server → browser → server on submit), so there's no
server-side session state to manage. Code-writing questions are graded by actually
running your submitted code against a hidden reference implementation inside a
`dotnet fsi` sandbox and comparing output.

## Study modes

Dashboard · Learn · Practice · Drill · Weaknesses · Exam · Review · Explore · Code Lab —
all reachable from the sidebar once the app is running.

## Content labelling

Every topic is tagged with where it came from, and the labels are never blurred:

- **Official Curriculum** — directly evidenced in current lecture material and/or recent
  exam papers.
- **Official but Not in Recent Exams** — genuine historical course material that hasn't
  appeared on any exam paper checked against.
- **Supplementary** — general knowledge used only to fill explanatory gaps, never
  presented as something the specific module taught.
